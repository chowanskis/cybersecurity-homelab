# Cybersecurity Homelab

Welcome to my personal cybersecurity homelab.

This repository documents the design, implementation, and continuous development of my cybersecurity laboratory. It serves as a technical portfolio showcasing practical experience in building, securing, monitoring, and testing enterprise-like environments.
The homelab is built using energy-efficient enterprise thin clients that provide a compact and affordable platform for cybersecurity experiments.

## Objectives
- Build a realistic enterprise network
- Learn defensive and offensive security
- Deploy SIEM and monitoring solutions
- Analyze attacks using PCAP files
- Automate security tasks
- Document every project and lesson learned
